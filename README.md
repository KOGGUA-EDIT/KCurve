# KCurve

**EffectCraft 的 Flow / Kease 风格缓动曲线编辑器。**  
单文件 ScriptUI 脚本，停靠在 EffectCraft 面板中，支持单段曲线、多点关键帧、超出边界和预设库。

![KCurve 在 EffectCraft 中](docs/screenshots/effectcraft.png?v=2.0.0)

当前版本：**2.0.0**  
适用：**EffectCraft 0.19.0**（停靠自适应是 0.19 专属）；旧版本未测试，不保证可用。

KCurve 把关键帧的缓动从数字参数变成一条可以拖的曲线：

- **单段模式**：拖两个控制点和两根操纵杆，直接编辑 `cubic-bezier(x1, y1, x2, y2)`；
- **多点模式**：每个点就是一个关键帧，可以加段、删点、切换平滑/折断；
- **超出边界**：默认限制在 0–1，也可以断开链条，让曲线冲出 0–1，做出弹性、回弹和夸张的过冲；
- **实时写入**：打开齿轮后，拖曲线会立即写回选中的关键帧；
- **反转曲线**：工具栏的反向双箭头把当前曲线做时间/值镜像，生成播放方向相反的缓动；
- **预设库**：Material 3 / Classic / 弹跳，全部可编辑，也可以保存自己的曲线；
- **折叠工具栏**：平时只剩 ☰、√ 应用和 ☆ 保存预设，点 ☰ 展开全部编辑工具（右键 ☰ 打开设置）；
- **中英双语**：右键 ☰ 打开设置，切换 中文 / English；
- **自适应停靠**：0.19.0 起面板跟着停靠区大小重排，编辑区、工具栏和预设库都不再固定在 340×530；
- **拖出面板也不断**：0.19.0 起拖动控制点或操纵杆越过面板边缘，曲线仍然跟手，松开鼠标才结束。

## 多点关键帧编辑

![多点关键帧编辑](docs/screenshots/multi.png?v=2.0.0)

多点模式每个控制点都会变成一个真正的时间线关键帧：

1. 在单段曲线上点 **+**，曲线会在中间切开，变成 3 个点；
2. 选中中间的点，拖动它的操纵杆，只改变相邻的两段；
3. **−** 删除选中的中间点，首尾点不能删；
4. **平滑 / 折断**按钮切换当前点左右操纵杆是否联动；平滑状态显示贝塞尔曲线图标，
   折断状态显示折线图标。单段模式下按钮变灰常驻（没有中间点可设置），点击会提示原因；
5. 首尾点固定在 **(0,0) / (1,1)**，不能拖动（只显示为曲线端点），可以拖它们的操纵杆；
6. **删除中间点**：选中后 **Alt+单击**，或右键点它选「删除这个点」。EffectCraft 0.19 的
   ScriptUI 不发送键盘事件，所以 Delete 键目前收不到（脚本已注册监听，宿主支持后即可用）；
7. 点 **√** 后，KCurve 会按首尾选中关键帧的时间范围，把所有点写成时间线关键帧。

截图里是一条多点曲线（「我的预设」组里是弹跳预设）：默认显示所有点的操纵杆，
也可以在设置里改成只显示选中点，避免多点曲线变成一团乱线。

## 超出边界（Overshoot）

![超出边界与实时写入](docs/screenshots/overshoot.png?v=2.0.0)

工具栏里的**链条图标**控制是否允许曲线超出 0–1：

- **链条连接**：值被限制在 0–1，适合普通缓动；
- **链条断开**：允许 `y < 0` 或 `y > 1`，可以做出弹簧、回弹、先冲过头再回来；
  **只放宽纵向值范围**，操纵杆的水平位置仍限制在所属段内；
- 导入已经带 Overshoot 的曲线时，KCurve 会自动打开这个开关；
- 编辑器里会画出 **0–1 的边界框**，方便看出曲线越界了多少；
- 预设缩略图也会按实际范围缩放，不会把过冲曲线压平。

## 单段曲线

![单段曲线](docs/screenshots/single.png?v=2.0.0)

- 横轴是时间 0–1，纵轴是值 0–1；
- 拖**锚点**改关键帧的值/时间位置；首尾点固定在 (0,0) / (1,1)，只能拖它们的操纵杆；
- **操纵杆限制在所属段内**：入杆只在「上一个点 → 本点」之间，出杆只在「本点 → 下一个点」之间，
  不会跨过相邻关键帧（相当于 AE 的 influence 0–100%）；首尾点同样限制在 0–1。
- 拖**操纵杆**改入/出切线；操纵杆可以直接拖到点上（比如 (0,0)），重叠时优先选中操纵杆；
- 编辑器只画曲线本身：没有顶部数值文本、没有网格，只有一条**蓝色描边**和一点点圆角；
- 面板不自己画背景，直接透出 EffectCraft 的界面底色（跟随主题和亮度）；
- 下方可以切换 **入侧 / 出侧 / 双侧** 写入；
- 选中关键帧后点 **√** 写入缓动；打开齿轮时拖动即实时写入。

> 截图里是从预设库载入的一条单段曲线；下方预设区可以直接点缩略图换曲线。

## 工具栏

平时只显示一行：**☰ 折叠按钮**、**√ 应用**（自动占满这一行剩下的宽度）、**☆ 保存预设**。
所有编辑工具默认折叠起来，点 ☰ 展开（再点收起）；展开后第一行最多放 **5 个工具**，
宽度不够或者工具更多时自动排到下面一行。工具和按钮都只在悬停 / 按下 / 选中时出现底色。

| 图标 | 功能 |
|---|---|
| 文档复制（两张叠放） | 从选中的关键帧导入曲线 |
| 反向双箭头 | 反转曲线（时间、值都镜像） |
| 链条 | 允许 / 禁止超出 0–1 |
| + / − | 增加 / 删除关键帧点 |
| 折线 / 贝塞尔曲线 | 平滑 / 折断操纵杆（单段模式变灰常驻） |
| 齿轮 | 实时写入开关：关=白色轮廓静止，开=整体蓝色实心并旋转 |
| 入 / 出 / 双侧 | 写入哪一侧的缓动 |
| 圆角勾 | 应用当前曲线（宽度自适应） |
| ☆ | 当前曲线保存为预设 |
| ☰ | 展开 / 收起工具栏；右键打开设置 |

应用按钮平时保留**蓝色描边**，悬停时叠加一层淡蓝底，按下时变成**实心蓝底 + 黑勾**。
导入、添加点、删除点、☆ 也使用同样的按下反馈（悬停淡蓝底、按下整格变蓝），
编辑器卡片使用**蓝色描边**。

### 设置菜单（1.0.13 起，1.1.3 起改为右键）

**右键**点 ☰ 打开：

- **语言**：English / 中文（带 ✓ 标记）；
- **预设库位置**：上侧（默认）/ 左侧 / 右侧；左侧和右侧时工具栏+编辑器是一块，
  预设库是另一块（面板太窄时自动仍按上侧，拉宽后生效）；
- **编辑器**：「只显示选中点的操纵杆」开关；默认关 = 所有点的操纵杆都显示，
  打开后只显示当前选中的点（✓ = 只显示选中点）；
- **工具栏**：「显示工具栏」整体开关（✓ = 展开）；
- **工具显示…**：单独勾选每个工具（导入、超出边界、添加点、删除点、平滑、实时写入、
  入侧、出侧、双侧），取消的工具不显示，工具行自动重排；
- **实时写入模式**：「停止拖动后写入」开关（✓ = 开）：
  - **开**：拖动只更新预览，松手时才写入时间线；
  - **关**：随时写入（默认，和以前一样）。

左键点 ☰ 直接展开 / 收起工具栏；工具栏的展开状态会记住，下次打开面板保持。

## 预设库

- 预设区没有标题文字，直接从组 chip 开始；
- 组是横向排列的 chip，宽度随文字变化；**最后一组后面的 +** 是新建预设组的槽位
  （跟着组 chip 一起换行，不再放在预设标题栏里）；
- 点击 chip 切换组，拖动 chip 可以调整顺序；
- 预设是正方形曲线缩略图，名称在下方；**拖动缩略图**可以在组内调整前后顺序，
  也可以拖到别的组 chip 上，把它移动进那个组；
- **☆ 保存**（工具栏应用按钮右侧）把当前曲线存进当前组；保存对话框只问名称和目标组，
  新预设不会跑到新建组里。要新建组，用组行最后的 **+**；
- **所有预设都可编辑**：Material 3 / Classic / 弹跳 / 我的预设都一样，右键可以
  **用当前曲线更新**、重命名、复制、删除；
- **弹跳组**不是内置演示曲线：升级到 1.0.9 时会把当时「我的预设」里的内容**复制一份**进来
  （之后两边互不影响）；新装则没有这个组，自己保存/复制进去即可；
- **经典组**从 1.1.14 起固定为 9 条曲线（曲线 1–9），旧版里的 Easy Ease / Linear 等已删除；
  升级时自动替换，组本身的位置不变。右侧可点 **+** 新建自己的组。
- 第一次升级到 1.0.5 时，内置的两组会一次性迁移成可编辑组（保留原来的曲线）；
- 组、预设、语言和工具栏展开状态都保存在 `app.settings`，重启不丢。

## 安装

1. 关闭 EffectCraft；
2. 把 `KCurve.jsx` 放进：

   `C:\Users\<用户名>\AppData\Roaming\EffectCraft\Scripts\ScriptUI Panels`

3. 启动 EffectCraft；
4. 从 **Window ▸ KCurve.jsx** 打开。

详细步骤见 [INSTALL.md](INSTALL.md)。

### 关于尺寸

**EffectCraft 0.19.0 起是自适应停靠面板**：宿主把停靠区的实际尺寸告诉脚本（`onResize` /
`scriptui.resize`），面板按新的宽高重排，不再固定 340×530。

- 停靠区更大：编辑区变高、预设库变宽，多出的空间都利用起来；
- 停靠区更小：先压缩编辑区，再压缩预设列表；最小布局 **200×300**，比这更小才出现滚动条；
- 预设库按实际宽度自动换列（窄时两列，宽时七列以上）；
- 设置里可以把预设库放到**左侧 / 右侧**；需要面板足够宽（编辑区至少 190px），
  太窄时自动保持上侧，拉宽后自动生效；
- 旧版 EffectCraft（0.13–0.18）拿不到停靠尺寸，仍按固定 **340×530** 绘制，行为和以前一样；
- 不提供独立浮动版入口，避免两个窗口和双份快捷键。

## 兼容与已知限制

- 0.19.0 修复了脚本绘制颜色过亮的问题（上游 #2272）；KCurve 按版本自动选择 **sRGB（0.19+）**
  或**线性（0.18 及更早）**颜色空间，同一套色板在 0.19 和旧版上看起来一致；
- EffectCraft **0.19.0** 实测（0.13 的脚本 API 兼容）；Windows 测试通过；
- 自定义画布没有局部重绘 API，所以是整块重绘；
- 0.19.0 起拖动会保持到松开：拖出面板边缘后 mousemove / mouseup 仍继续送到画布；如果平台在
  原生窗口外停止上报，脚本会在下一次收到移动时用 `buttons === 0` 兜底收尾。0.13–0.18 没有
  鼠标捕获，拖出窗口仍会按旧逻辑结束拖拽；
- 没有滚轮事件，预设列表使用滚动条或拖动空白区域；
- 停靠区小于 200×300 时宿主才会出现滚动条。
